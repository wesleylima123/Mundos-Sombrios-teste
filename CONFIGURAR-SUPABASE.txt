CONFIGURAÇÃO RÁPIDA — MUNDOS SOMBRIOS

1) Execute supabase-install-completo-v2.10.1.sql no projeto Supabase escolhido.
   (Não rode os arquivos de sql/historico/: são só histórico.)
2) Edite js/ms-runtime-config.js.
3) Preencha somente:
   url: 'https://SEU-PROJETO.supabase.co'
   publishableKey: 'SUA_CHAVE_PUBLICA'
4) Nunca use service_role, secret key ou senha do banco no frontend.
5) Em Auth > URL Configuration, inclua o endereço do site publicado.
6) Publique no GitHub Pages ou em qualquer hospedagem estática.

Sem URL/chave o site não funciona: não existe modo offline nesta versão.
